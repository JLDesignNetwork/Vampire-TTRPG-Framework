# Vampire TTRPG Framework (v2608.19.0-as)

Welcome to the **Vampire TTRPG Framework** (JLDN Generational Versioning Schema: `2608.19.0-as`).

## Overview

This repository contains the master ruleset specification for the system-agnostic, multi-genre **Vampire TTRPG Framework**.

- **Master Ruleset File:** [vampire-2608.md](./vampire-2608.md)
- **Author:** Jeff Langdon (JL Design Network)
- **Ruleset Version:** `2608.19.0-as` (Public Alpha)

## Core Features

- **System-Agnostic Architecture:** Adaptable to modern urban fantasy, dark fantasy, sci-fi, and horror settings.
- **Dynamic Age Tiers:** Distinct mechanics for Neonates (<500 yrs), Elders (500–1,199 yrs), and Ancients (1,200+ yrs).
- **Formal Action Economy:** Structured turn architecture (Main Action, Movement/Minor Action, Sustained Upkeep, Off-Turn Reaction) with Age-Tiered Blood Reserve Expenditure Caps.
- **Vampiric Physiology & Banes:** Sunlight Disintegration Progression, Native Soil Dependency, The Bleed, and Decapitation Brain Torpor rules.
- **Extensive Powers Engine:** Innate, Activated, Sustained, and Master Composite powers across Behavioral and Supernatural disciplines.
- **Social & Coven Governance:** Coven Laws (Shroud, Haven Sanctuary, Sanguine Tithe, Tabula Rasa), Chronicler Synchronized Network, and Blood Archives.
